# Форматы журналов и очереди деплоя

Файлы-состояния, через которые автозадачи координируются между собой (каждая работает в отдельной сессии без общей памяти).

## boost-log.csv — журнал усилений (article-boost)

```
date,slug,trigger,base_query,base_pos,base_ctr,base_time,base_kurs_click,changes,risk_edits,control_date,result
```

- `base_*` — метрики «до» правок (позиция главного запроса, CTR, время на странице, клики в продукт).
- `risk_edits` — рискованные правки (title/H1) с текстом «до» для отката.
- `control_date` — дата контрольной сверки (обычно +7 дней).
- `result` — пусто, пока контроль не прошёл; затем `ok` / `rollback`.

Автозадача каждый прогон сверяет строки с наступившей `control_date`: позиция ухудшилась на ≥1.5 пункта → автоматический откат рискованных правок.

## refresh-log.csv — журнал ротации-актуализации (articles-refresh)

```
date,slug,verdict,edits,notes
```

`verdict`: актуальна / N правок / отклонено / kimi не успел. Статья не берётся в ротацию повторно 30 дней.

## .deploy-queue.local.json — очередь общего деплоя (вне git!)

Дневные задачи не деплоят сами — пишут запись в очередь, финализатор в 15:00 выкатывает всё одним циклом (одна сборка, один коммит, один деплой, одна прод-проверка, один переобход):

```json
[{
  "source": "conveyor | refresh | boost",
  "date": "YYYY-MM-DD",
  "commit_paths": ["course/articles/slug.md", "public/articles/img/cover-slug.svg"],
  "delete_paths": ["course/articles/slug--preview.md"],
  "check_urls": ["/articles/slug"],
  "check_images": ["/articles/img/cover-slug.svg"],
  "check_facts": [{"url": "/articles/slug", "expect": "фрагмент нового факта"}],
  "recrawl_urls": ["/articles/slug", "/stati"],
  "sitemap": true,
  "notes": "человекочитаемая сводка"
}]
```

Принципы: финализатор деплоит СТРОГО очередь (незаявленные файлы и чужой WIP не трогает); любая ошибка на стоп-шаге сохраняет очередь для следующего прогона; обработанное уезжает в `.deploy-queue.done-<дата>.json` как история.

## Зачем это всё

Экономия: минус две пересборки, минус 2–3 деплой-цикла с 20-минутными поллингами, минус лишние переобходы — порядка 15–20К токенов LLM в день только на обвязке. Плюс прод дёргается один раз, и деплой-локи параллельных задач не толкаются.
