Ежедневный аналитический свод по сайту skillmake.ru. ВАЖНО: всю аналитику делает Kimi CLI — ты НЕ анализируешь данные сам и не тратишь на это токены. Твоя роль: запустить Kimi, дождаться, показать результат. Общайся на русском.

## Шаги

1. **Определи отчётную дату** = ВЧЕРА по московскому времени (машина на MSK, UTC+3). Формат YYYY-MM-DD.

2. **Запусти Kimi** из папки `<workspace>` (в фоне, это займёт 3–8 минут). Команда через Bash-инструмент (обязательно `</dev/null`, иначе демон повесит пайп):

```
cd "<workspace>" && "kimi" -p "Прочитай бриф llm-shared/kimi-daily-report-brief.md и ВЫПОЛНИ его полностью. Отчётный день (вчера) = <ВЧЕРА>. Собери отчёт за вчера + накопительный свод из llm-shared/seo-daily-history.csv, обнови файл-историю (допиши строку за вчера, дозаполни пустые ячейки за 1-2 прошлых дня если лаг Вебмастера прошёл), сохрани отчёт в llm-shared/daily-report-<ВЧЕРА>.md И выведи целиком в ответ. Строго соблюди структуру: сначала ЧАСТЬ A (требует действия -> главные цифры -> выводы -> рекомендация), потом ЧАСТЬ B (детальные таблицы). Включи раздел поддержки (виджет + почта support@ по IMAP) с отсевом тестовых и спама. Работай автономно, не задавай вопросов. Секреты из <файл секретов вне git> НЕ печатай." </dev/null > llm-shared/kimi-daily-run.log 2>&1
```
Запускай с `run_in_background: true` и дождись завершения.

3. **Проверь результат**: файл `llm-shared/daily-report-<ВЧЕРА>.md` должен появиться. Прогони скан, что в нём НЕ засветился секрет БД (сравни с значением `<ИМЯ_ПЕРЕМЕННОЙ_СЕКРЕТА>` из <файл секретов вне git> — если найден, вырежи его из файла и сообщи об утечке).

4. **Покажи пользователю** содержимое отчёта — ЦЕЛИКОМ, как есть, без своих правок и без пересказа. Это результат Kimi.

5. **Если Kimi упал** (нет файла отчёта / exit != 0): посмотри хвост `llm-shared/kimi-daily-run.log`, сообщи причину коротко и НЕ пытайся собрать отчёт сам.

## Контекст (для понимания, не для пересбора)
- Бриф со всеми доступами и командами: `llm-shared/kimi-daily-report-brief.md` (Вебмастер, Метрика, Google Search Console, App Store Connect установки, прод-БД, поддержка).
- Накопительная история по дням: `llm-shared/seo-daily-history.csv` — Kimi сам её дополняет.
- Отчёты складываются в `llm-shared/daily-report-<дата>.md`.
- Лаги данных: Яндекс.Вебмастер 1–2 дня, Google Search Console ~2 дня, App Store ~1–2 дня (HTTP 404 = 0 установок, это норма).
