# Бриф: статьи-объяснялки для курса skillmake.ru

Ты пишешь бесплатные статьи для блога курса «Собери своё первое приложение с ИИ — без кода» (skillmake.ru). Аудитория: взрослые новички из РФ без опыта программирования; они проходят курс, где ИИ (Claude Code) пишет код за них, а они учатся ставить задачи. Учебный проект курса — браузерная игра «Змейка» (HTML/JS, позже PWA и Supabase).

## Формат файла (СТРОГО)

Markdown-файл со frontmatter:

```
---
title: <ДО 65 СИМВОЛОВ, поисковая фраза ближе к началу; можно отшлифовать формулировку задания>
excerpt: <ДО 160 СИМВОЛОВ, 1-2 предложения с поисковой фразой. Без кликбейта.>
tag: <ровно одно: Объяснялка | Практика | Бизнес>
date: 2026-07-03
read: <N мин — реалистичная оценка: ~150 слов/мин>
---

![<alt по теме>](img/cover-<slug>.svg)

<тело статьи>
```

## Стиль

- Обращение на «ты», дружелюбно, без сюсюканья. Русский язык, технические термины поясняются при первом употреблении.
- Структура: короткое интро с проблемой читателя (2-4 предложения) → разделы `##` (каждый H2 — подвопрос темы, как его ищут в поиске) → практический блок («как применить/проверить») → **блок FAQ: 3-5 частых вопросов** (`## Частые вопросы` + `### Вопрос?` + короткий ответ) → короткое заключение.
- 800–1500 слов. Без воды: каждый абзац несёт мысль.
- Примеры — на «Змейке» или простых житейских аналогиях, где уместно.
- Списки и таблицы — где они реально помогают, не для украшения.

## ЗАПРЕЩЕНО (проверяется вручную, статьи с нарушениями возвращаются)

1. **Выдумывать факты**: точные цены сторонних сервисов, точные шаги их интерфейсов, лимиты API, даты. Если нужно — пиши «актуальные тарифы смотри на сайте сервиса». Общеизвестные стабильные вещи (что такое localStorage, HTTP, npm) — можно уверенно.
2. Обещания дохода/заработка, «гарантированно заработаешь», «пассивный доход». Слова про деньги — только с оговорками «зависит от продукта и рынка».
3. Ссылки на несуществующие статьи/страницы. Внутренние ссылки — ТОЛЬКО на слаги из списка существующих статей, если он дан в задании (2-3 уместные), иначе не ставь. Внешние ссылки — только на официальные сайты/доки (https://supabase.com/docs и т.п.), не более 2-3 на статью.
4. Упоминание конкурентов-курсов, политики, медицины.
5. Английские кальки («заимплементить», «зареджектить») — пиши по-русски.

## Контекст курса (для связности, НЕ пересказывай)

- Модуль 1: настройка окружения (VPN, зарубежная карта, Claude, GitHub, Node).
- Модуль 2: сборка «Змейки» промптами (localStorage для рекорда).
- Модуль 3: публикация на GitHub Pages, публичная ссылка, бейдж «Сделано на курсе».
- Модуль 4: качество — скины, звук, магазин, PWA/офлайн, автотесты.
- Модуль 5: Supabase — аккаунты, общая таблица рекордов, аналитика.
- Модуль 6 (август): «От приложения к доходу». Модуль 7: публикация в сторы.
